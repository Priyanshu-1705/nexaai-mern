# NexaAI 🤖

An AI-powered conversational assistant built using the MERN stack. NexaAI enables users to interact with an intelligent chatbot through a modern, responsive, and user-friendly interface.

## 🚀 Features

- AI-powered chatbot
- Responsive modern UI
- User authentication
- Chat interface
- Dark mode support
- Real-time conversational experience
- Secure backend integration

> More features coming soon...

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- React Router DOM

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Other Tools
- Git & GitHub
- REST APIs
